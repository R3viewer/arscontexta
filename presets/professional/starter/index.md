# executive overview

This is your professional memory hub. It separates durable institutional knowledge (`notes/`) from raw meeting/reading captures (`inbox/`), client deliverable drafting (`deliverables/`), and short-term execution tasks (`ops/tasks.md`, week-to-month horizon).

## Core Context Maps

- [[engagements]] — Bounded client missions and projects, each with your stated role/expertise and parallel workstreams
- [[responsibilities]] — Ongoing Lead, Manager, and governance scopes that evolve continuously without a fixed end date
- [[expertise]] — Transverse skills, domain watch, and reusable patterns that carry from one mission to the next
- [[network]] — Clients, teammates, decision-makers, and professional contacts with key context and expectations

## How Work Flows Here

1. Capture raw meeting notes, reading notes, ideas, or incoming deliverables in `inbox/`.
2. Run `/distill` to extract durable insights into `notes/` (and route short-term actions to `ops/tasks.md`), then move processed sources to `archive/`.
3. Draft client outputs in `deliverables/` by pulling sourced `[[insights]]` and decisions from `notes/`, and capitalize key outcomes back into memory once delivered.
4. Keep `status` and `updated` dates current so `/align` and health checks catch stale decisions, paused streams, or orphan knowledge notes.
